# Tidebound Fishing

A browser prototype of a 2D fishing game built with plain HTML, CSS, JavaScript modules, Canvas, Web Audio, and `localStorage`.

## Run

Use a tiny local server so ES module imports work consistently:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

You can also use:

```bash
npx serve .
```

## Play

Hold and release `Cast` or the spacebar, hook the bite, then hold/release during the reel fight to keep the marker inside the green zone. Sell catches from the inventory, buy rods, bait, and boats in the shop, and track discoveries in the Fish Dex.
